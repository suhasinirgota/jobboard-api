# Job Board API

A RESTful API built with Node.js, Express, and MySQL for managing companies and job listings.

## Tech Stack
- Node.js + Express.js
- MySQL with mysql2
- dotenv for environment variables

## Setup

1. Clone the repository
```bash
git clone https://github.com/yourusername/jobboard-api.git
cd jobboard-api
```

2. Install dependencies
```bash
npm install
```
